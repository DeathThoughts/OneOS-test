# ROM visual redesign

The existing home carousel, artwork resources, ordering, support filtering and per-version actions remain intact. The selector now uses a scrollable, bottom-aligned native dialog with actual version artwork, localized state, explicit single selection and confirmation. Each of the ten catalog families has a local gradient palette in light/dark modes. The preboot page retains the original launch gates and fix actions, with a compact portrait banner, edition information, adaptive status tiles, a themed fixed action and earlier access to app/debloat controls. Wide layout retains its two-pane art. No guest, image, download, stage, boot or patch logic changed. Physical UI and accessibility testing are required; mockup glow is intentionally simplified to inexpensive gradients.
